# Seedcast 打包说明（mac / win · 引擎 sidecar）

## M0-T13 结论：引擎打包选 Bun compile

| 方案 | 结论 | 原因 |
|---|---|---|
| **Bun `--compile`** | **采用** | 本机（darwin arm64）实测：单文件可启动 HTTP、打开 SQLite（better-sqlite3）、`channel: chrome` 拉起 Playwright；体积约 90MB |
| Node SEA + vendor | 备选 / 不优先 | 可行，但需旁路分发 `better-sqlite3` / `playwright`，布局与 `NODE_PATH` 更碎 |
| 纯 Node SEA 单文件 | 否 | 原生模块无法可靠嵌入单一 blob |
| Bun 作为开发运行时 | 否 | 日常开发仍用 **Node ≥20 + pnpm**（与现有脚本一致） |

约束（发行期仍成立）：

- **按目标 OS/架构本机或 CI 矩阵编译**，不做跨编译（原生依赖）
- **不打包 Chromium**：继续依赖本机 Google Chrome（`channel: 'chrome'`）
- Windows 产物在 `windows-latest` 上构建；mac 在 `macos-latest`（arm64；Intel 另跑或交叉机）

## 本机手工出包（M1）

### 前置

- Node ≥20、pnpm ≥9、Rust（Tauri 2）、**Bun**（仅 sidecar）
- macOS：Xcode CLT；Windows：WebView2 + NSIS（Tauri 默认）
- 本机已装 **Google Chrome**

### 步骤（推荐脚本）

```bash
cd code
./scripts/build-mac.sh                 # install → build → sidecar → dmg
# ./scripts/build-mac.sh --skip-install
# ./scripts/build-mac.sh --sidecar-only
# ./scripts/build-mac.sh --dev-check   # 仅编译检查
```

手动等价：

```bash
cd code
pnpm install
pnpm --filter @seedcast/engine build
pnpm --filter @seedcast/engine sidecar   # → src-tauri/binaries/seedcast-engine-<triple>
pnpm --filter @seedcast/app tauri:build
```

产物位置（典型）：

- macOS：`…/bundle/dmg/Seedcast_*.dmg`（本机也可复制到 `apps/desktop/dist-bundle/`）
- Windows：`…/bundle/nsis/*.exe`

说明：若环境设置了 `CARGO_TARGET_DIR`（如 CI/沙箱），产物在该目录下而非 `src-tauri/target`。

### sidecar 命名

Tauri `externalBin` 约定：

```
binaries/seedcast-engine-aarch64-apple-darwin
binaries/seedcast-engine-x86_64-apple-darwin
binaries/seedcast-engine-x86_64-pc-windows-msvc.exe
```

构建脚本只生成**当前机器**对应的一份；其它 triple 需在对应 runner 上执行 `sidecar`。

### 官方插件

`sidecar` 脚本会把 `code/plugins/{mock,zhihu,wechat-mp}` 同步到  
`apps/desktop/src-tauri/resources/plugins`，随包进入 Resource；壳拉起引擎时设置：

```text
SEEDCAST_BUILTIN_PLUGINS=<resource>/plugins
```

## 签名与公证（可暂缓）

| 平台 | M1 | M2+ |
|---|---|---|
| macOS | 可无签名本地装；Gatekeeper 需右键打开 | Apple Developer 签名 + Notarization |
| Windows | 未签名可能触发 SmartScreen | 代码签名证书 |

## 已知限制

1. sidecar 约 90MB，安装包显著大于「纯壳」
2. 无 Chrome 时浏览器类插件不可用（公众号 draft API 不依赖浏览器）
3. `tauri build` 前必须先有对应平台的 sidecar 文件，否则 bundler 失败
4. Linux 发行仍为 P2
5. 引擎 CORS 必须放行 `tauri://` / `https://tauri.localhost`；否则发行包 WebView 会报 `Load failed`

## 冒烟建议

```bash
# 直接跑 sidecar（独立于 Tauri）
SEEDCAST_DATA_DIR=/tmp/seedcast-sidecar-smoke \
  ./apps/desktop/src-tauri/binaries/seedcast-engine-$(node -p "process.arch==='arm64'&&process.platform==='darwin'?'aarch64-apple-darwin':'…'") 

# 或
pnpm --filter @seedcast/engine smoke:pw
```

安装 dmg/nsis 后：启动 App → 自动拉起引擎 → 账号页能列出内置插件。
