# 抖音插件

- 状态：创作者中心「发布文章 / 图文」写入草稿（页面自动化）。
- 实测日期：待补（插件加载 / 无账号发布拦截先测；真实账号草稿写入需扫码后补）。

## 选型

| 优先级 | 结论 |
|---|---|
| 官方开放 API | 「发布内容至抖音」偏移动 App SDK，且对企业主体/资质有门槛，不适合本机个人桌面工具 |
| 现成方案 | 社区多为 Cookie + 签名 Web API 或 Playwright 操作创作者中心；签名链路脆弱，opencli 等已改回页面流程 |
| 本插件 | Cookie 会话检测（`web/api/media/user/info`）+ **有头 Playwright** 填创作者中心草稿 |

## 发布类型

| id | 标签 | 说明 |
|---|---|---|
| draft | 写入创作者中心草稿 | 文章走「发布文章」编辑器；图文走上传页素材 + 标题/文案后「暂存离开」 |

本版不做短视频分片上传（M3）。
